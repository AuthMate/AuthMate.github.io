よくある質問

Auth Mateは無料ですか？

はい。無料版には無制限のOTPアカウント、QRコードスキャン、暗号化バックアップなどが含まれています。Plus（$3.99）とPro（$19.99）はオプションの買い切り購入です。

データはどこに保存されますか？

すべてのデータは端末のiOS Keychainにローカル保存されます。サーバーは運用していません。

既存のアカウントをインポートするには？

アプリを開き、「アカウント追加」→「QRコードをスキャン」を選択してください。

PlusとProの違いは？

Plusはプレミアムテーマ、AutoFill、アプリロックを解除。ProはさらにiCloud同期、Widget、Face ID、Siri統合を追加します。

サブスクリプションはありますか？

いいえ。すべての購入は買い切りで、永久アクセス権です。
