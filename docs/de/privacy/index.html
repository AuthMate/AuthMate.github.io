Datenschutzrichtlinie

Zuletzt aktualisiert: 21. Juli 2026

Alle Kontoinformationen werden standardmäßig lokal im iOS Keychain auf Ihrem Gerät gespeichert. Diese Daten werden niemals auf einen Server hochgeladen.

Datenspeicherung

Alle Kontoinformationen werden standardmäßig lokal im iOS Keychain auf Ihrem Gerät gespeichert. Diese Daten werden niemals auf einen Server hochgeladen.

Was wir nicht sammeln

Keine Kontodaten, Geräteinformationen oder eindeutigen Identifikatoren. Keine Analyse- oder Absturzbericht-SDKs. Keine Drittanbieter-Tracker.

Kamera & Biometrie

Kamera: Nur beim Scannen von QR-Codes angefordert. Face ID/Touch ID: Nur zum Entsperren der App verwendet.

In-App-Käufe

Premium-Designs und -Funktionen werden durch In-App-Käufe im App Store freigeschaltet. Auth Mate liest nur das Kaufresultat.

Kontakt

Bei Fragen kontaktieren Sie uns bitte unter: support@authmate.app
