Tester un compte TOTP

Ajoutez ce compte de test à n'importe quelle application d'authentification — manuellement ou en scannant le QR code — puis saisissez le code à 6 chiffres qu'elle génère pour vérifier que tout fonctionne.

URI otpauth

Compte
test@authmate.lyy.app
Secret (base32)
JBSWY3DPEHPK3PXP
Émetteur
Auth Mate
URI otpauth
otpauth://totp/Auth%20Mate:test@authmate.lyy.app?secret=JBSWY3DPEHPK3PXP&issuer=Auth%20Mate&algorithm=SHA1&digits=6&period=30&domain=authmate.lyy.app

Scanner pour ajouter

Ouvrez votre application d'authentification et scannez ce QR code pour ajouter le compte de test instantanément.

Vérifier votre code

Saisissez le code à 6 chiffres affiché dans votre application d'authentification. Les codes corrects sont acceptés, les incorrects rejetés — le champ sert aussi à vérifier l'AutoFill d'iOS.

Testez l'AutoFill de mot de passe iOS : en touchant le champ nom d'utilisateur, iOS propose les mots de passe enregistrés pour ce site. Toute valeur convient, elle n'est pas vérifiée.

Ajout manuel : utilisez le nom de compte et le secret ci-dessus, avec l'émetteur "Auth Mate" et un TOTP SHA1 de 30 secondes.

Astuce AutoFill iOS : scannez le QR code avec l'appareil photo de votre iPhone et enregistrez-le dans la base de mots de passe du système. En touchant le champ de code ci-dessous, iOS affiche le code au-dessus du clavier.
