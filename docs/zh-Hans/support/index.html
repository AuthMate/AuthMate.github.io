常见问题解答

Auth Mate 是否免费？

是的。免费版包含无限 OTP 账号、二维码扫描、加密备份导出、时钟偏差检测等核心功能，且无任何数量限制。Plus（¥28）和 Pro（¥138）为可选的一次性购买，用于解锁更多高级主题和功能。所有购买均为永久解锁，无需续费。

我的数据存储在哪里？

所有数据默认仅存储在设备本地的 iOS Keychain 中。如果你在设置中开启 iCloud 同步，数据将通过 iCloud Keychain 在设备间同步（端到端加密）。我们没有任何服务器，也无法访问你的数据。

如何导入我的现有账号？

打开 App，点击"添加账号"，选择"扫描二维码"。你可以扫描其他验证器（如 Google Authenticator）生成的 otpauth:// 二维码，或使用 otpauth-migration:// 批量迁移。

Plus 和 Pro 有什么区别？

Plus（¥28）解锁 16 款高级主题、键盘自动填充验证码和应用锁。Pro（¥138）包含 Plus 全部内容，另加 iCloud Keychain 同步、桌面小组件、Face ID 自动解锁、Siri 与 Shortcuts 集成。如果你不确定，可以先从 Plus 开始，之后可以补差价升级到 Pro。

是否有年费订阅？

没有。所有购买均为一次买断，永久解锁。我们不使用订阅模式，因为 2FA 用户的核心诉求是"装上就用"，订阅违背这个心智。
