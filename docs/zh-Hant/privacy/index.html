隱私政策

最後更新：2026 年 7 月 21 日

你添加的所有帳號資訊（服務名、使用者名稱、密鑰）預設僅儲存在本機的 iOS Keychain 中。這些資料不會上傳到任何伺服器。如果你在設定中開啟了 iCloud 同步，資料會通過 Apple 的 iCloud Keychain 在你的裝置間同步（端到端加密）。解除安裝 App 即永久刪除。

資料儲存位置

你添加的所有帳號資訊（服務名、使用者名稱、密鑰）預設僅儲存在本機的 iOS Keychain 中。這些資料不會上傳到任何伺服器。如果你在設定中開啟了 iCloud 同步，資料會通過 Apple 的 iCloud Keychain 在你的裝置間同步（端到端加密）。解除安裝 App 即永久刪除。

我們不收集的內容

不收集帳號內容、裝置資訊或唯一識別碼。不使用分析或崩潰報告 SDK。不使用任何第三方追蹤、廣告或歸因 SDK。不使用 IDFA。

相機與生物識別

相機：僅在掃描 QR Code 時申請，掃描後即丟棄串流。Face ID / Touch ID：僅在解鎖 App 時使用，驗證由 iOS 本地完成。

應用內購買

高級主題與功能通過 App Store 內購解鎖。Auth Mate 只能讀取購買結果，無法獲取你的 Apple ID 或支付資訊。

備份匯出

匯出功能生成包含種子碼的 JSON 檔案，由你全權管理。可選 AES-GCM 加密。不會自動備份或上傳。

兒童隱私

我們不會故意收集 13 歲以下兒童的任何資訊。

政策變更

重大變更時會在 App 內顯示通知並更新日期。
