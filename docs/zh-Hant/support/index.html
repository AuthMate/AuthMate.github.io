常見問題解答

Auth Mate 是否免費？

是的。免費版包含無限帳號、QR Code 掃描等核心功能。Plus（$3.99）和 Pro（$19.99）為可選的一次性購買。所有購買均為永久解鎖。

我的資料儲存在哪裡？

所有資料預設僅儲存在裝置本地的 iOS Keychain 中。我們沒有任何伺服器。

如何導入現有帳號？

打開 App → 點擊"添加帳號" → 選擇"掃描 QR Code"。

Plus 和 Pro 有什麼區別？

Plus 解鎖高級主題、鍵盤自動填入和應用鎖。Pro 另加 iCloud 同步、Widget、Face ID 解鎖和 Siri 整合。

是否有年費訂閱？

沒有。所有購買均為一次買斷。
