당신의 코드, 당신의 통제

프라이버시 우선의 2차 인증 앱. 서버 불필요. 회원가입 불필요. 광고 없음. 원격 측정 없음. 완전 오프라인. 특별 설계된 iCloud 동기화 알고리즘으로 데이터를 절대 잃지 않습니다

많은 계정을 가진 사용자에 최적화 — 일괄 가져오기, 스마트 검색, 모든 규모에서 손쉬운 관리。

App Store에서 다운로드iOS 16.0+무료. 프리미엄 기능만 구매 필요（구독 또는 일회성 구매）。

필요한 모든 것

프라이버시를 존중하는 완전한 기능의 인증 앱.

∞

무제한 계정

필요한 만큼 2FA 계정을 추가하세요. 인위적인 제한이 없습니다.

QR 코드 가져오기

otpauth:// 또는 otpauth-migration:// QR 코드를 스캔하여 즉시 가져오기.

Face ID, Touch ID, 마스터 비밀번호 또는 6자리 PIN으로 보호.

🎨

아름다운 테마

기본 라이트/다크 2개 테마 무료. 수십 개의 프리미엄 테마 잠금 해제.

암호화된 백업

AES-GCM 암호화로 계정 내보내기. 데이터를 완전히 통제하세요.

시계 오차 감지

기기 시계 오차를 자동 감지하여 코드 실패 전 경고.

⚡

배치 모드

대량 계정 관리를 위한 일괄 작업 — 삭제, 숨기기 등.

↕

계정 정렬

드래그로 계정 순서 변경. 재시작 후에도 유지됨.

👁

계정 숨기기

계정을 메인 목록에서 영구적으로 숨깁니다.

📋

다중 버전 백업

암호화된 백업의 여러 기록 버전을 보관.

◆

사각/둥근 스타일

사각형 또는 둥근 아이콘 스타일 선택 가능.

프라이버시 우선. 항상.

2FA 시크릿은 오직 당신만의 것이라는 원칙으로 만들어졌습니다.

서버 불필요

서버를 운영하지 않습니다. 모든 데이터는 기기에만 저장됩니다.

종단간 암호화 동기화

iCloud 동기화는 Apple의 종단간 암호화 Keychain을 사용합니다. 우리도 읽을 수 없습니다.

추적 없음, 분석 없음

분석 SDK, 충돌 리포트, 타사 추적기 전혀 없음. IDFA 미사용, ATT 프롬프트 없음.

계정 불필요

즉시 사용 가능 — 가입, 로그인, 계정이 전혀 필요하지 않습니다.
