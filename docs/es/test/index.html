Probar una cuenta TOTP

Añada esta cuenta de prueba a cualquier aplicación de autenticación (manualmente o escaneando el código QR) y luego introduzca el código de 6 dígitos que genera para verificar que todo funciona.

URI otpauth

Cuenta
test@authmate.lyy.app
Secreto (base32)
JBSWY3DPEHPK3PXP
Emisor
Auth Mate
URI otpauth
otpauth://totp/Auth%20Mate:test@authmate.lyy.app?secret=JBSWY3DPEHPK3PXP&issuer=Auth%20Mate&algorithm=SHA1&digits=6&period=30&domain=authmate.lyy.app

Escanear para añadir

Abra Auth Mate y escanee este código QR para añadir la cuenta de prueba al instante.

Verifique su código

Introduzca el código de 6 dígitos que muestra su aplicación de autenticación. Los códigos correctos se aceptan y los incorrectos se rechazan.

Añadir manualmente: use el nombre de cuenta y el secreto de arriba, con el emisor "Auth Mate" y TOTP SHA1 de 30 segundos.
